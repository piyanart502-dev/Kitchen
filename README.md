## โหมดทดลอง กับ โหมดใช้งานจริง

- **ยังไม่ได้ใส่ลิงก์ Apps Script** แอปจะขึ้นแถบเหลือง "โหมดทดลอง" ข้อมูลที่บันทึกจะอยู่ในมือถือเครื่องนั้นเครื่องเดียว เหมาะสำหรับลองกดดูเท่านั้น
- **ใส่ลิงก์ Apps Script แล้ว** ทุกเครื่องจะเห็นข้อมูลชุดเดียวกัน บันทึกลง Google Sheets ของหน่วยงาน และรูปบ่อดักไขมันเก็บในโฟลเดอร์ Google Drive ชื่อ `KITCHEN WORK - รูปบ่อดักไขมัน`

## เชื่อม Google Sheets (ทำครั้งเดียว ประมาณ 15 นาที ใช้คอมพิวเตอร์)

### ส่วน A: ตั้งค่า Google

1. เข้า [sheets.google.com](https://sheets.google.com) ด้วยบัญชี Google ของหน่วยงาน กด **สเปรดชีตเปล่า** แล้วตั้งชื่อ `KITCHEN WORK ข้อมูล`
2. เมนู **ส่วนขยาย > Apps Script**
3. เปิดไฟล์ [`KITCHEN-WORK.gs`](KITCHEN-WORK.gs) ในหน้านี้ กดปุ่ม **Copy raw file** (รูปสี่เหลี่ยมซ้อนกัน มุมขวาบนของโค้ด) แล้ววางทับโค้ดเดิมทั้งหมดใน `code.gs` กด **Ctrl+S**
4. ที่ช่องเลือกฟังก์ชัน เลือก **setup** แล้วกด **▷ เรียกใช้**
   - ครั้งแรกจะขอสิทธิ์: กด **ตรวจสอบสิทธิ์** > เลือกบัญชี > **ขั้นสูง** > **ไปที่ KITCHEN WORK (ไม่ปลอดภัย)** > **อนุญาต** (เป็นสคริปต์ของเราเอง)
   - เสร็จแล้วในไฟล์ชีตจะมีแผ่นงาน Temps, GreaseWeeks, StockItems, StockMoves และ Settings
5. กด **การทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่** > ⚙ เลือก **เว็บแอป**
   - เรียกใช้งานในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (สำคัญมาก ถ้าเลือกอย่างอื่นแอปจะเชื่อมต่อไม่ได้)
   - กด **ทำให้ใช้งานได้** แล้ว **คัดลอก URL** ที่ขึ้นต้นด้วย `https://script.google.com/macros/s/` และลงท้ายด้วย `/exec`

### ส่วน B: ใส่ลิงก์ในแอป (แก้บนเว็บ GitHub ได้เลย)

1. ในหน้านี้ กดไฟล์ `index.html` แล้วกดรูปดินสอ ✏️ (**Edit this file**)
2. กด **Ctrl+F** ค้นหา `API_URL` จะเจอบรรทัด
   ```js
   const API_URL = 'วางลิงก์ /exec ตรงนี้';
   ```
3. ลบคำว่า `วางลิงก์ /exec ตรงนี้` แล้ววางลิงก์จากส่วน A แทน โดยเครื่องหมาย `'` หัว-ท้ายต้องอยู่ครบ เช่น
   ```js
   const API_URL = 'https://script.google.com/macros/s/AKfycbx…/exec';
   ```
4. กด **Commit changes…** > **Commit changes** รอ 1–2 นาที แล้วเปิดลิงก์แอปใหม่ แถบเหลืองจะหายไป และมุมขวาบนจะมีปุ่มรูปตารางสำหรับเปิดไฟล์ Google Sheets

> ส่งลิงก์ /exec มาในแชทกับ Claude ก็ได้ จะใส่ให้

### อัปเดตโค้ดหลังบ้านภายหลัง

วางโค้ดใหม่ทับใน `code.gs` > **การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้** > ✏️ > เวอร์ชัน **เวอร์ชันใหม่** > **ทำให้ใช้งานได้** ลิงก์ /exec จะเหมือนเดิม จึงไม่ต้องแก้ `index.html` (ถ้าเผลอสร้าง "รายการใหม่" จะได้ลิงก์ใหม่ ต้องทำส่วน B ซ้ำ)

## ตั้ง PIN (แนะนำ)

ใครได้ลิงก์ก็เปิดแอปได้ PIN ช่วยกันคนนอกไม่ให้ดูหรือบันทึกข้อมูล

1. ใน Apps Script ค้นหา `var PIN = '1234';` แก้เป็นตัวเลข 4–6 หลักที่ต้องการ แล้ว **Ctrl+S**
2. เลือกฟังก์ชัน **setPin** กด **▷ เรียกใช้**
3. แก้ตัวเลขในโค้ดกลับเป็น `1234` แล้ว Ctrl+S ได้ (ระบบเก็บ PIN จริงไว้แยกแล้ว)
4. มือถือแต่ละเครื่องใส่ PIN ครั้งแรกครั้งเดียว เครื่องจะจำไว้

ยกเลิก PIN: เลือกฟังก์ชัน **clearPin** แล้วกด ▷ เรียกใช้ (ไม่ต้องอัปเดตเวอร์ชันเว็บแอป)

## สแกนบาร์โค้ด

- **รับเข้า**: หน้า สต๊อก > **↓ รับเข้า** > **เปิดกล้องสแกนโค้ด** เล็งบาร์โค้ดให้อยู่ในกรอบ ถือนิ่งจะนับ 1 ชิ้น เอาออกจากกรอบแล้วเล็งขวดถัดไป กด **เสร็จแล้ว** เมื่อครบ จำนวนจะเติมให้อัตโนมัติ
- **เบิกออก**: หน้า สต๊อก > **สแกนเบิกออก** > **เปิดกล้องสแกนบาร์โค้ด** ระบบจะเปิดรายการนั้นให้กรอกจำนวนเบิก
- ครั้งแรกมือถือจะถามสิทธิ์ใช้กล้อง ให้กด **อนุญาต** ถ้ากล้องสดใช้ไม่ได้ (เช่น ในหน้าเว็บของ LINE บางเครื่อง) ให้กด **ถ่ายรูปแทน** หรือกด ⋮ > เปิดในเบราว์เซอร์

## ข้อควรระวัง

- **ห้ามสลับ แทรก หรือลบคอลัมน์** ในไฟล์ Google Sheets เพราะระบบอ่านข้อมูลตามลำดับคอลัมน์ (เพิ่มแถว แก้ค่า หรือดาวน์โหลดเป็น Excel ได้ตามปกติ)
- โปรเจกต์นี้เป็น **Public** ทุกคนเห็นโค้ดหน้าแอปได้ รวมถึงรายชื่อพนักงานที่ตั้งไว้ในโค้ด แต่ **ไม่เห็นข้อมูลที่บันทึก** เพราะข้อมูลอยู่ใน Google Sheets และ Drive ของหน่วยงาน
- สำรองข้อมูลเดือนละครั้ง: เปิดไฟล์ชีต > **ไฟล์ > ดาวน์โหลด > Microsoft Excel**
